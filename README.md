# Site IA Generator

Ferramenta local para criar páginas a partir de uma imagem de referência e de uma descrição textual.

## Como usar

1. Abra o arquivo `index.html` no navegador.
2. Descreva o tipo de site que deseja.
3. Escolha uma imagem de referência.
4. Clique em `Criar site automaticamente`.
5. Ajuste o resultado com a caixa de edição ou baixe o HTML final.

## Funcionalidades

- Upload de imagem como referência visual
- Geração de layout com texto + hero + estrutura HTML
- Visualização em tempo real
- Edição rápida do código
- Download do projeto em HTML
- 100% local, sem backend e sem servidor

## Observação

A ferramenta foi criada para funcionar em navegador moderno, sem depender de pacotes externos. Basta abrir o arquivo e usar.
